# Mobile Browser Game

An empty, mobile-ready browser game scaffold built with Vite and npm. The game area is a responsive canvas; add rendering and input handling in `src/main.js`.

## Development

```sh
npm install
npm run dev
```

To open the dev server on a phone on the same network, use the network URL printed by Vite.

## Build

```sh
npm run build
npm run preview
```
